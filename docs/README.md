# docs

| Folder | What goes in it |
| --- | --- |
| `adr/` | One file per design decision, with the options and trade-offs (copy `0000-template.md`) |
| `notes/system-design/` | Short notes on the fundamentals behind the design: API design, data modeling, indexes, caching, replication and sharding, queues, consistency, idempotency, rate limiting |
| `notes/java-depth/` | Notes on Java, Spring and SQL topics, each linked to an example in the code |
| `designs/` | Longer system design write-ups (payment system, settlement scheduler, webhook intake, multi-tenant storage); copy `TEMPLATE.md` |
